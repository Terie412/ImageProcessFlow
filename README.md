# ImageProcessFlow

纯本地的**可视化图像处理流水线编辑器**：在画布上摆节点、连线，把若干图像处理步骤编排成一条流水线，手动逐步执行。

一个**工作目录**里可以放**多个画布**（各有一套节点 / 连线 / 图片池），一个画布专注做一件事。左侧还有一块**资源面板**，可以把工作目录之外的一个素材目录当图库用。

处理节点：**AI 生图 / 编辑**、**裁剪**、**区域抹除**、**按透明度抹除**、**调整分辨率**、**正方形扩展**、**单色替换**、**透明度缩放**、**色彩平衡**。拼图、格式转换等脚本按同样的方式随时可以加。

---

## 快速开始

```bat
start.bat                 :: 界面里再选工作目录
start.bat -w <工作目录>   :: 直接指定
```

浏览器打开 **http://127.0.0.1:8770**。生图需要环境变量 `DASHSCOPE_API_KEY`（Qwen 模型）与 `GPT-IMAGE-2-KEY`（GPT Image 模型）；润色 / 自动识别需要 `DEEPSEEK_API_KEY`。

### 基本操作

1. **指定工作目录** —— 点顶栏左边的路径方块。所有东西都放在里面，工具**不会碰目录以外的文件**。
2. **选画布** —— 顶栏「画布」下拉，`＋` 新建、`✎` 改名、`⋯` 删除（会连图片池一起删，**最后一个画布不给删**）。
3. **加数据节点** —— 把图片拖进画布、用「＋ 导入图片」，或从**左侧资源面板**把图片拖进来。图片会被**复制**一份进当前画布的图片池。
4. **加处理节点** —— 在画布**空白处点右键**，从菜单里选。
5. **连线** —— 从图片节点右侧的圆点拖到处理节点左侧的输入口。
6. **填提示词** —— 输入口栏**从上往下数第几行**，提示词里就写 `参考图N`（如 `只保留参考图1中的人物`）。原样发给模型，不做改写。写不好点「润色」。
7. **点「▶ 执行」** —— 跑完在右侧长出输出图片节点，标题栏显示耗时。执行日志默认不显示（要看就 ⚙ → 勾「显示执行日志」）。

### 常用操作

- **换画布**：画布之间完全独立，执行不跨画布级联；各自记住缩放平移。
- **跨画布搬节点**：选中后 `Ctrl+C`，切画布 `Ctrl+V`（粘到视野中心）或右键「粘贴到此处」。图片文件跟着复制一份并在新画布重新编号。
- **看大图**：双击任意图片节点全屏查看，默认「适应窗口」，可切「实际大小」（双击图片也能切）；透明区垫棋盘格，顶栏实时显示光标处像素。`Esc` 关闭。**资源面板里的图片双击也是它**（同一个查看器）。
- **在图上丈量尺寸**：在查看器里**按住左键拖动**，拖出一个半透明框，顶栏实时显示它的**像素宽高与左上角坐标**（如 `600 × 600px @ (300, 200)`）。松手框就消失，读数留在顶栏 —— 用来量图里某个元素占多少像素。
- **下载图片**：数据节点上的「下载」把图另存到别处（「覆盖」则直接写回上次那个位置）。对话框默认打开**这个节点上次保存的目录**；**从没下载过**的节点则打开**最近一次下载的目录** —— 不用每次从工作目录根翻起。
- **编辑区域**：双击裁剪 / 区域抹除节点上的预览图（或点「编辑」）—— 拖空处新建、拖框内移动、拖四角改大小、`Delete` 删除；**点「保存」才写回**。
- **删除节点**：选中后按 `Delete` / `Backspace`，这是唯一入口。只有删**数据节点**才可能弹确认框（它对应磁盘文件）；可在 ⚙ 里关掉确认。
- **增减输入口**：行右侧 `−` 删掉这一个，栏底常驻的 `＋` 在末尾加一个（**一个不剩时它也在**，不会把自己锁死）。删中间的之后**后面的会前移**（`参考图3` → `参考图2`），但**提示词里的序号不会自动改**。
- **一键填充输入**：输入栏底部的 `⇥` —— 把画布上**选中的数据节点**按「离这个节点的距离」依次填进输入口（最近的那个是「参考图1」）。端口数量**多删少补**（选了 4 个就变成 4 个口，原先 8 个也砍到 4），已连的**覆盖**，**这个节点自己产出的**图会被排除。固定单口的节点（裁剪 / 区域抹除）只填最近的一个。
- **摆乱了**：画布空白处右键 →「画布 → 格式化所有节点」，按依赖分层重排，**任意两个节点都不重叠**；右键 →「撤销格式化」可退回（只能用一次）。
- **改节点大小**：拖节点**右下角**（那里没有可见的手柄，鼠标移到角落会变成斜向的双箭头），改完记住。每种节点类型的**初始尺寸**在 ⚙ → 节点尺寸里调（第一个数字是宽、第二个是高）；**最小尺寸不可配**，所有类型统一 200×200 写死在代码里，所以初始尺寸填多小都会被顶到 200。
- **网格吸附**：⚙ → 勾上后节点吸到格点（默认 5px，1~200 可调），勾上那一刻整块画布会对齐；背景那层 20px 格子只是阅读参考。
- **缩放吸附**：⚙ → 「缩放吸附」填一个步长（默认 10px），拖右下角改大小时宽高就只能是它的整数倍（填 10 → 200、210、220…）；**填 0 或负数 = 关闭**。只作用于拖动改尺寸，已存下来的老节点不受影响。
- **尺寸选「自动」**：不是让模型自己挑，是**按最后一张参考图在下拉里就近选一个**，生成前就显示在节点上（`自动 → 720×1280`）。没有参考图时才交回模型。
- **执行日志**：默认不显示。⚙ → 勾上「显示执行日志」，执行节点时右下角出现实时日志面板（跑完保留最近一次）；面板上的「关闭」就是把这项关掉。脚本的 stdout 原样打在这里。

## 从零开始（克隆后首次运行）

```bat
:: 1) 后端依赖（venv 必须建在 runtime\venv，start.bat 写死了这个路径）
python -m venv runtime\venv
runtime\venv\Scripts\python.exe -m pip install -r requirements.txt

:: 2) 前端构建（产物到 server\static，不构建界面打不开）
cd web && npm install && npm run build && cd ..

:: 3) 起服务
start.bat
```

环境要求：Python 3.10+、Node 18+（**只在构建前端时需要**）。国内装依赖慢可以加 `-i https://pypi.tuna.tsinghua.edu.cn/simple`。

三个最容易卡住的点：

1. **venv 必须在 `runtime\venv`**。想用别的解释器就别走 bat，直接 `python server\main.py -w <工作目录>`。
2. **必须先 `npm run build`**，否则打开 8770 是 **404**（后端只在 `server/static` 存在时才挂载静态目录）。做前端开发改用 `npm run dev`。
3. **`start.bat` 必须是 CRLF 行尾** —— 批处理里有中文，LF 行尾会让 cmd 算错字节偏移、满屏 `'...' 不是内部或外部命令`（服务其实照样起得来，只是难看）。修复：`git rm --cached start.bat && git checkout start.bat`。

> 首次启动不会有 `settings.json`（用默认值生成），这是正常的。

## 处理节点

| 节点 | 一句话 |
| --- | --- |
| **AI 生图 / 编辑** | 一个节点、两套后端：Qwen（DashScope）与 GPT Image（OpenAI 兼容）。**参数随所选模型切换**。输入口可增减，全空 = 文生图，有连线 = 图生图 |
| **裁剪** | 按区域把一张图裁成多张 |
| **区域抹除** | 把指定区域内的东西抹掉，输出同尺寸 |
| **按透明度抹除** | 把 alpha 低于阈值的像素 RGB 置 0（alpha 不动） |
| **调整分辨率** | 强制缩放到指定宽高 |
| **正方形扩展** | 短边两侧居中补透明，补成正方形 |
| **单色替换** | 全图 RGB 换成一种颜色，Alpha 不变 |
| **透明度缩放** | 每个像素的 alpha × 一个系数 |
| **色彩平衡** | 整体色调沿 黄↔蓝 / 绿↔品红 两条轴平移 |

**共通的**：除裁剪 / 区域抹除外大多支持**多输入** —— 有几个输入口连了图就产出几张，输出序号与输入口对齐（没连线的口跳过）。带 Alpha 的输出一律存 **PNG**；不带 Alpha 的**跟随原图格式**。

各节点容易踩的点：

- **裁剪 / 区域抹除**：区域坐标是**原图像素**、原点左上，共用同一个编辑器。裁剪没有提示词（纯几何切分）；区域为空时裁剪会报错、区域抹除则原样复制。
- **区域抹除抹成什么**取决于源图**实际有没有 Alpha**（不是文件后缀）：有 → 透明 + PNG；没有 → 黑 + 跟随原格式。**RGB 模式的 PNG 算「没有」**，抹完是黑的、不会凭空加 alpha。
- **按透明度抹除**阈值 0~255（默认 8，和查看器里的 `A` 同尺度），严格「低于」才抹；没有透明通道的图原样复制。
- **调整分辨率**宽高比不一致会**拉伸变形**（刻意的，不猜意图）；「保持比例」只认第一个连了图的输入口，其余连线保留但不生效。
- **单色替换**会把明暗层次一起抹掉 —— 那是调色，不是替换。
- **色彩平衡**两条轴都为 0 时原样复制；「保持亮度」（默认开）让整张图平均亮度不动。
- **AI 生图 / 编辑**的模型脾气、`size` 分隔符、两套参数如何按模型切换等细节见 `MODEL_NOTES.md` 和 `DESIGN.md` §3.4。

## 提示词润色

提示词框右下角的 **「润色」** 按钮：把**当前提示词 + 该节点连着的参考图 + 当前生图模型的特点**发给文本模型（DeepSeek），拿回改写后的提示词**覆盖**输入框，可「撤销」还原。

它解决的是：生图模型对「背景」「UI」这类抽象说法定位不到，会把内容整个删掉。润色就是把这些话展开成**具体的视觉描述**。

- **透明参考图会先合成到灰白棋盘格再发**，并告诉模型「棋盘格 = 透明区域」—— 视觉模型看不见 alpha，否则会把透明区当成白底写进提示词。没有透明通道的图原样发送。这是自动的，不用设置。
- **密钥**：⚙ → 「提示词润色」里填**环境变量的名字**（默认 `DEEPSEEK_API_KEY`）—— key 本身不落进配置文件，也不显示在界面上。
- 它只是"把话说明白"，**不会**让生图模型变得更能干。

## 资源目录面板

左侧的**资源面板**把「工作目录之外」的一个素材目录整个当图库用。顶栏 **「资源」** 按钮开合（状态会记住）。

- **指定**：面板里「浏览…」选目录，或填完整路径回车。路径**跟随工作目录**保存。
- **拖到画布**：图片**拖进画布**就建一个数据节点（落在松手的位置），拖的是**副本**，原文件不动。
- **双击预览**：双击图片文件打开大图查看器 —— 和双击数据节点是**同一个窗口**：滚轮缩放、中键平移、适应窗口 / 实际大小、看光标处像素值、`Esc` 关闭。
- **右键管理**：空白处右键 →「新建目录」（建在资源目录根）；目录上右键 →「新建目录」（建在那个目录下）+「重命名」「删除」；文件上右键 →「重命名」「删除」。只能**建目录不建文件**；**删除进回收站**，可以找回来。
- **懒加载**：进入只读根目录一层，展开子目录时才去读那一层。**展开到哪一层会被记住** —— 刷新页面、点 ↻ 刷新、收起再打开面板，都还是原来展开的样子（按资源目录分开记，换机器/换浏览器则回到全折叠）。
- 目录可展开；**图片**显示缩略图；**非图片文件**灰显、不可拖（能看到结构，但不是可用素材）。
- 拖动只带一个相对路径，服务端直接复制 —— 大图不经浏览器上传。
- **调宽**：拖面板的右边缘即可改宽，双击那条边恢复默认；宽度会记住。
- 一次只能拖**一个**文件；拖整个文件夹、一次拖多个、目录内搜索都还没做。

## 核心概念

| 概念 | 说明 |
| --- | --- |
| **工作目录** | 项目。里面可放多个画布，所有文件都在里面（工具的目录沙箱）。`graph.json` 就是项目文件 |
| **资源目录** | 工作目录之外的素材来源，路径跟随工作目录保存。面板里可拖图建节点、右键新建目录 / 改名 / 删除（删除进回收站） |
| **画布** | 项目里的一张画布：自己的节点 / 连线 + 自己的图片池 + 自己的视野，各画布完全独立 |
| **图片池** | 每个画布一份（`canvases/<画布id>/images/`），短名只在本画布内唯一 |
| **数据节点** | 一张图片（输入型 = 你拖进来的；输出型 = 节点产出的） |
| **处理节点** | 执行一个脚本：有输入口、输出口、参数控件 |
| **输出槽位** | 处理节点的第 N 个输出。重执行按序号**原地刷新**；输出变少时多出的槽位连同文件一起删除 |
| **图片名** | 短名 `A`、`B`…，文件名主干就是它。**只用于标识，不参与提示词** |
| **引用输入图** | 提示词里写 `参考图N`（N = 输入口栏从上往下数）。引擎**原样透传** |

**执行语义**：改参数不触发重算；执行一个节点只跑它自己（不级联下游）；执行后**直接下游处理节点被标脏**（紫色圆点）；重执行按**输出序号**重绑连线，序号没了的断开并**永久删除文件**；执行**失败**时旧输出原封不动。完整规则见 `DESIGN.md` §2.2。

## 扩展：新增一个处理节点

1. 在 `scripts/` 下建一个目录，放 `manifest.json` + `.py`
2. **重启服务**（`start.bat`）—— 脚本注册表在启动时扫一次 `scripts/`，新节点随即出现在右键菜单

```jsonc
{
  "id": "my_script",
  "name": "显示在节点上的名字",
  "entry": "my_script.py",
  "inputs": [
    { "key": "image", "type": "image", "dynamic": true, "label": "参考图",
      "count": 1, "min": 0, "max": 10 }
  ],
  "params": [
    { "key": "prompt", "type": "text",   "label": "提示词", "primary": true, "default": "" },
    { "key": "n",      "type": "number", "label": "张数", "width": "narrow", "default": 1 }
  ],
  "outputs": [{ "key": "image", "type": "image", "multi": true }]
}
```

- `params[].type`：`text` / `number` / `enum` / `bool` / `color` / `slider`（带 min/max/step）/ `regions`（区域数组 `[{x,y,w,h}]`，原图像素）。
- `params[].width`：`grow`（吃掉整排剩余宽度）/ `narrow`（定宽小格）/ `full`（独占一排），不写就是普通宽度。
- `primary: true` 的参数占节点主体；**不要写 `hint`** —— 低频说明放文档里。
- **`detect` 段**（可选）声明节点支持「自动识别」以及模型可调的参数，写法见 `scripts/crop/manifest.json`，机制见 `DESIGN.md` §3.8。

**脚本契约**（详见 `DESIGN.md` §2.5）：

```
stdin  ← 一行 JSON: {"params": {...}, "inputs": {"image1": 路径或 null}, "output_dir": 目录}
stdout → 日志，原样显示在节点上
产出   → 写进 output_dir，命名 0.png、1.png…（序号即输出槽位顺序）
成败   → 退出码 0 = 成功；非 0 = 失败，错误写 stderr
```

目录树、工作目录布局、各模块职责见 `DESIGN.md` §3。

## 开发

```bat
cd web && npm run dev                                          :: 前端热更新（5173，API 代理到 8770）
cd web && npm run build                                        :: 构建到 server/static
runtime\venv\Scripts\python.exe server\main.py -w <工作目录>   :: 直接跑后端
```

> 重装前端依赖后若 `vite build` 报 `Cannot find module @rollup/...`（沙箱注入的 `NODE_OPTIONS` 垫片会让 npm 漏装 optional 依赖）：
> `cd web && npm install @esbuild/win32-x64@0.21.5 --save-exact && npm install @rollup/rollup-win32-x64-msvc@4.64.5 --save-exact`

**测试脚本**（都在 `runtime/`；带 ⚠️ 的会真实调用付费 API。纯本地的直接跑，需要界面的先起 `start.bat` 再把 URL 传进去 —— 用哪个参数见脚本自己的注释）：

| 脚本 | 验证什么 |
| --- | --- |
| `verify_sizes.py` | 节点尺寸唯一口径 / 下限恒 200 / 改设置当场生效 / 不落盘 |
| `verify_slots.py` | 输出槽位落点按实际尺寸算、互不重叠 |
| `verify_layout.py` | 整图排版：零重叠 / 边向右 / 幂等 / 吸附 / 撤销 |
| `verify_canvases.py` | 多画布：v1 迁移 / 每画布图片池 / 跨画布复制粘贴 / 删画布隔离 |
| `verify_snap.py` | 网格吸附：就近 vs 向上 / 开启时收齐 / 排版仍满足间距下限；缩放吸附：设置项归一与往返 |
| `verify_autosize.py` | 自动尺寸：就近匹配 / 界面与执行同口径 / 只算不写 |
| `verify_polish_flatten.py` | 润色参考图棋盘合成 |
| `verify_resize.py` · `verify_region_erase.py` · `verify_alpha_erase.py` · `verify_color_balance.py` | 各几何 / 调色脚本：格式跟随、alpha、错误分支 |
| `verify_resourcedir.py` | 资源目录：路径穿越防护 / 列目录 / 拖进画布 = 复制且原文件不动 / 新建目录·改名·删除与名字校验 |
| `verify_export_dir.py` | 下载落点：节点自己的记忆 / 全局记忆 / 新节点落到上次的目录 / 取消不写记忆 |
